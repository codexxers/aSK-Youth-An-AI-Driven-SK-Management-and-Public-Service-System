# Events & Attendance — Page Guide

---

## Overview

- Used to track, manage, and analyze SK youth events
- Has two main tabs: **Analytics** and **Manage Events**

---

## Tab 1 — Analytics

### Stat Cards *(top row)*

- Shows **5 summary numbers** at a glance: Total Events, Upcoming, Completed, Total Attendees, and Total Budget
- Always visible regardless of which chart tab is active

### Chart Tabs

- **By Event** — Compares attendee count per event (bar chart)
- **By Month** — Shows how many events occurred each month
- **By Status** — Pie chart of upcoming vs. completed events
- **Attendance** — Attendance breakdown per event
  - Checkbox: **Show Male/Female Breakdown** — adds gender bars per event
  - Checkbox: **Show Staff Participation** — adds staff count bars

---

## Tab 2 — Manage Events

### Toolbar

- **Search box** — Filters events by title or category as you type
- **Category dropdown** — Narrows the list to one category (sports, seminar, health, etc.)
- **Status dropdown** — Shows only Upcoming or Completed events
- **+ Add Event button** — Opens the event form to create a new entry

### Event Cards

- **Date block** (left) — Month and day shown at a glance
- **Title, time, category badge, status badge** — Quick identification
- **Description** (if set) — Short preview text
- **Info chips** — Attendee count, male/female split, staff count, budget
- **Edit** — Opens the form pre-filled with the event's current data
- **Delete** — Asks for confirmation before permanently removing the event

---

## Add / Edit Event Form

### Import from Document *(available on Add only)*

- Upload a document (PDF, DOCX, image, TXT, CSV) and click **Extract**
- The system scans the file and auto-fills matching event fields
- Always review the extracted values before saving

### Basic Info Fields

- **Title** — Name of the event
- **Category** — sports, seminar, scholarship, assembly, community, livelihood, cultural, health, general
- **Status** — Upcoming or Completed
- **Date / Time** — When the event is scheduled
- **Location** — Venue
- **Organizer** — Person or group running the event
- **Description** — Brief summary
- **Requirements** — Any prerequisites or needed items
- **Contact** — Contact person or number

### Attendance & Budget Fields

- **Attendees** — Total head count
- **Male / Female** — Gender breakdown of attendees
- **Staff** — Optional; SK staff who assisted
- **Budget Allotted (₱)** — Budget in Philippine Pesos

Click **Create** (or **Update** when editing) to save. Click **Cancel** to close without changes.

---

## Delete Confirmation

- Clicking **Delete** on an event card opens a confirmation dialog
- Click **Delete** again to remove permanently, or **Cancel** to go back

---

## Quick Summary

- **Analytics tab** — 5 stat cards (events, attendees, budget) + 4 interactive charts (By Event, By Month, By Status, Attendance with gender/staff toggles)
- **Manage Events tab** — searchable, filterable event list with date, category, status, and attendance info per card
- **Add Event** — full 15-field form with optional document import (PDF, DOCX, image, TXT) that auto-fills fields
- **Edit Event** — same form pre-filled; document import not available when editing
- **Delete Event** — always asks for confirmation before removing
- Changes to events instantly reflect in both the list and analytics charts
