\## Style Notes for the AI Agent



When filling in this scaffold, follow these conventions:



1\. \*\*Second person, present tense.\*\* "You can…", "Click…", "Your dashboard shows…"

2\. \*\*Short, direct sentences.\*\* Aim for 8–12 words per sentence.

3\. \*\*Numbered steps for every walkthrough.\*\* "To do X: 1. … 2. … 3. …"

4\. \*\*Callout letters (A, B, C, D).\*\* Every screenshot has lettered markers that match the steps.

5\. \*\*Icons for each feature\*\* in the highlights section — one icon + one title + one line of copy.

6\. \*\*Notes and Tips in italics\*\*, prefixed with \*\*Note:\*\* or \*\*Tip:\*\*.

7\. \*\*Cross-references\*\* always point to a chapter + section title, not just a page number.

8\. \*\*No marketing fluff.\*\* Warm but restrained.

9\. \*\*Consistent product name.\*\* Always "aSK Youth".

10\. \*\*Localise lightly.\*\* Mention Barangay Concepcion Dos, Marikina City, and Filipino-language prompts are OK if the UI supports them.

\## How to Use This Scaffold



1\. Hand this entire document to your AI agent as the \*\*skeleton\*\*.

2\. Attach your \*\*system context\*\* — the 8 modules, the 4 roles, the tech stack, the workflow diagrams, and the UI screenshots.

3\. Ask the AI agent to \*\*fill in the italic bracket sections\*\* using the system context and the style notes.

4\. Review each output for tone, cadence, and visual density.

5\. Insert screenshots with callouts A–D into the final Word or Canva file — the AI agent can suggest which callouts belong on which screenshot.
